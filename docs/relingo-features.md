# Relingo 기능 조사 (readgloss 대비)

조사: 설치본 v3.30.1 파일, relingo.net, 외부 리뷰. 워크플로 wzc8aykwz.


**지금 readgloss가 Relingo에서 가져온 것.** 영어 단어를 더블클릭하면 맥 영한사전 카드가 뜨고(발음·품사·뜻·예문, `[AI 문맥 뜻]` 버튼 포함), 문단을 클릭하면 AI 한국어 번역을 원문 아래에 끼워 넣습니다. 어려운 단어(B2 이상) 위에는 사전 첫 뜻이 작은 글씨(ruby, 단어 위에 얹는 작은 주석)로 자동으로 붙습니다. 이 기능들은 컴퓨터 안의 작은 서버("다리")와 캐시로 돌아갑니다. 설정 화면, 툴바 팝업, 떠 있는 패널, 단어장, 복습은 아직 없고, 영상 기능은 범위 밖으로 정했습니다.

**읽는 법.** 상태는 ✅ 있음 / 🟡 비슷하게 있음 / ⬜ 없음 / 🚫 범위 밖입니다. 크기는 S(반 세션 이하) / M(한 세션) / L(두 세션 이상)이고 ⬜·🟡에만 붙습니다. `(AI)`는 구독 AI 한도를 쓴다는 뜻이고, ⭐는 이미 요청해서 다음 회차에 넣기로 한 항목입니다.

## 1. 읽기 보조 (어려운 단어를 찾아 표시)

1. **단어 강조 켜기/끄기** — 전체를 끄거나 "이번 페이지만" 잠깐 끕니다. · 🟡 (기본 켜짐만 있고 끄는 스위치 없음) · S
2. **어려운 단어 위 자동 주석** — 단어 위에 뜻을 작게 붙입니다. · ✅
3. **주석 위치 고르기** — 단어 위 / 단어 오른쪽 / 없음 중에서 고릅니다. · 🟡 (위 방식만 있음) · S
4. **수준(난이도) 고르기** — 내 영어 수준에 맞춰 A2~C2 사이에서 고릅니다. 수준이 높을수록 주석이 줄어듭니다. · 🟡 (B2 이상으로 고정) · S
5. **시험 단어장 기준 강조** — IELTS·TOEFL·GRE 단어를 기준으로 강조합니다. · ⬜ · M
6. **내 어휘 수준 추정 모드** — 내가 아는 단어를 추정해서 모르는 단어만 최대한 표시합니다. · ⬜ · L
7. **주석 수 줄이기** ⭐ — 문단당 최대 개수와 같은 단어 반복 규칙을 정합니다. Relingo에는 없고 요청 항목입니다. · 🟡 (문단마다 첫 등장만 있음) · S
8. **새 단어 번역 흐리기** — 뜻을 흐리게 가려 두고 떠올려 본 뒤 확인합니다. · ⬜ · S
9. **단어 진행 표시** — 강조된 단어에 몇 번 봤는지 같은 표시를 붙입니다. (확인 약함) · ⬜ · M

## 2. 모양·표시

10. **주석 모양 값 조정** ⭐ — 글자 크기·색·투명도를 숫자와 선택으로 바꿉니다. 색 기본은 본문색입니다. Relingo에도 이 설정은 없고(색 상속·투명도 60% 고정), readgloss가 새로 만듭니다. · ⬜ · S
11. **단어 강조 방식 5종** — 배경 / 주석만 / 점선 밑줄 / 배경+주석 / 밑줄+주석 중에서 고릅니다. · ⬜ · S
12. **강조 색 규칙** — 단어 빈도, 수집 여부별로 색을 달리 줍니다. · ⬜ · M
13. **품사 색 표시** — 명사·동사·형용사·부사를 색으로 구분합니다. (베타) · ⬜ · M
14. **주석 글자 복사 허용** — 주석을 드래그해서 복사할 수 있게 합니다. · ⬜ · S
15. **화면 테마** — 자동 / 밝게 / 어둡게. · ⬜ · S
16. **설정 미리보기** — 값을 바꾸면 예시 문장이 바로 바뀝니다. · ⬜ · S

## 3. 단어 조회

17. **더블클릭 단어 카드** — 발음·품사·뜻·예문이 든 카드입니다. Relingo는 올림이나 클릭으로 엽니다. · ✅
18. **카드 여는 방식 고르기** — 더블클릭 / 클릭 / 마우스 올림 / 안 열기. · ⬜ · S
19. **발음 재생과 발음 설정** — 소리 재생, 미국/영국식, 볼륨, 자동 재생, 발음 글자 크기. · 🟡 (발음 표기만 있고 소리 재생 없음) · S
20. **사전 여러 개** — 옥스포드·콜린스 같은 다른 사전을 탭으로 바꿉니다. 맥에 깔린 다른 사전부터 쓰면 쉽습니다. · ⬜ · M
21. **동의어·반의어·관련어·단어 빈도** — 카드에 추가 정보를 붙입니다. · ⬜ · M
22. **AI 문맥 뜻** — 지금 문장에 맞는 뜻을 AI가 설명합니다. · ✅ (AI)
23. **단어 변형형 보기** — 과거형·복수형 같은 활용형을 보여 줍니다. · ⬜ · S
24. **예문 번역** — 예문마다 한국어 번역을 붙입니다. · 🟡 (예문은 있고 번역 없음) · S (AI)
25. **뜻 직접 고치기·메모·기억 이미지** — 기본 뜻을 바꾸고, 메모를 달고, 외우기용 그림을 붙입니다. · ⬜ · M

## 4. 번역

26. **문단 번역** — Relingo는 문단에 마우스를 올리고 키를 누르면 번역하고, 다시 누르면 닫습니다. · 🟡 (readgloss는 클릭→왼쪽 버튼 방식, 다시 누르면 제거) · S (AI)
27. **선택한 글 번역 카드** — 글을 드래그하면 번역 카드가 뜹니다. 카드 이동·복사·문장 쪼개기도 됩니다. · ⬜ · M (AI)
28. **전체 페이지 번역** — 원문+번역 또는 번역만으로 페이지 전체를 번역합니다. 한도를 가장 많이 씁니다. · ⬜ · L (AI)
29. **전체 번역 모양 값** — 번역 글자 투명도, 글자 크기, 스타일(기본/점선/흐림/인용). 28번이 있어야 합니다. · ⬜ · S
30. **AI 문법 분석** — 문장 구조와 핵심 구문을 패널로 풀어 줍니다. · ⬜ · M (AI)
31. **빠른 번역 창** — 웹페이지 밖에서 단어·문장을 입력해 바로 번역합니다. · ⬜ · M (AI)
32. **입력 상자 강화** — 입력창에 쓰다가 스페이스를 누르면 영어로 바꿔 줍니다. (베타) · ⬜ · M (AI)
33. **번역 엔진 고르기** — Google·DeepL·OpenAI 등을 고릅니다. API 키가 필요해 "구독으로만" 방침과 충돌하므로 추천하지 않습니다. · ⬜ · L

## 모양 설정

### Relingo가 제공하는 값 (설치본 기준)

| 항목 | 값 범위 | 기본값 |
|---|---|---|
| 단어 강조 방식 | 배경 / 주석만 / 점선 밑줄 / 배경+주석 / 밑줄+주석 | 배경+주석 |
| 주석 위치 | 오른쪽 / 위 / 없음 | 오른쪽 |
| 주석 글자 크기·색·투명도 | **설정 없음** (본문과 같은 크기·같은 색, 투명도 60% 고정) | 해당 없음 |
| 강조 색 규칙 | 조건(수집 여부, 빈도 0~5, 단어장)+색 선택, 규칙 여러 개 | 규칙 없음 |
| 품사 색 | 명사·동사·형용사·부사별 켜기+색, 방식은 글자색/배경/밑줄 | 품사 표시 꺼짐 (켜면 명사·동사만) |
| 발음 글자 크기 | 9~15px | 12px |
| 전체 번역 투명도 | 0~100 | 30 |
| 전체 번역 글자 크기 | 50~200% | 90 |
| 전체 번역 스타일 | 기본 / 점선 밑줄 / 흐림 / 인용 | 기본 |
| 전체 번역 모드 | 원문+번역 / 번역만 | 원문+번역 |
| 새 단어 번역 흐리기 | 켜기 / 끄기 | 꺼짐 |
| 단어 카드 여는 방식 | 마우스 올림 / 클릭 / 안 열기 | 마우스 올림 |
| 테마 | 자동 / 밝게 / 어둡게 | 자동 |
| 떠 있는 버튼 위치 | 오른쪽 가장자리, 세로만 (40px ~ 창 높이-40px) | 위에서 60px |
| 떠 있는 버튼 클릭 동작 | 패널 열기 / 강조 전환 | 패널 열기 |
| 영상 자막 글꼴·크기·위치·배경 | 🚫 범위 밖 | 해당 없음 |

공식·외부 자료에서 더 나온 모양 항목은 병음 글자 크기와 단어 카드 너비 정도였습니다. 표의 값은 설치본 코드에서 읽은 것이라 가장 믿을 만합니다.

### readgloss 설정 패널 추천 초안

패널 맨 위에 예시 문장 미리보기(16번)를 두고, 값을 바꾸면 바로 반영되게 합니다. "값 범위"는 슬라이더나 숫자 입력으로 만들 수 있는 범위입니다.

| 항목 | 값 범위 | 추천 기본값 |
|---|---|---|
| 주석 켜기/끄기 | 켜짐 / 꺼짐 | 켜짐 |
| 주석 위치 | 단어 위 / 단어 오른쪽 / 없음 | 단어 위 |
| 주석 글자 크기 | 본문의 40~100% | 60% (지금보다 작게) |
| 주석 색 | 본문색 / 강조색 / 직접 고르기 | **본문색** |
| 주석 투명도 | 30~100% | 70% |
| 주석 글자 굵기 | 얇게 / 보통 / 굵게 | 보통 |
| 단어 간격 (주석 때문에 벌어지는 정도) | 0~0.3em | 0 |
| 주석 단어 표시 방식 | 없음 / 점선 밑줄 / 배경 형광 / 둘 다 | 없음 (화면이 덜 복잡해짐) |
| 밑줄·배경 색 | 본문색 흐리게 / 강조색 / 직접 | 본문색 흐리게 |

| 문단당 주석 최대 개수 | 0~10 (0 = 제한 없음) | 3 |
| 같은 단어 반복 | 문단마다 첫 등장 / 페이지에서 한 번만 / 항상 | 문단마다 첫 등장 (지금 방식) |

| 화면 테마 | 자동 / 밝게 / 어둡게 | 자동 |

## 떠 있는 패널

Relingo의 구성은 아래와 같습니다. 설치본 코드에서 확인했고, 공식·외부 자료에는 모양 세부가 없습니다.

- **떠 있는 버튼.** 화면 오른쪽 끝에 붙은 작은 둥근 버튼입니다. 세로로만 끌어 옮기고(기본 위에서 60px), 끌어서 놓은 위치가 저장됩니다. 마우스를 올리면 ✕(닫기)가 나타나고, 닫은 뒤에는 설정에서 다시 켭니다.
- **퀵 메뉴.** 버튼에 마우스를 올리면 전체 텍스트 번역(켜져 있으면 체크 표시), 나중에 읽기 추가, 빠른 번역, 설정이 펼쳐집니다. 버튼 동작이 "강조 전환"이면 "현재 단어 목록 열기"도 들어갑니다. 항목마다 단축키가 함께 보입니다.
- **오른쪽 패널.** 버튼을 클릭하면 열립니다. 기본 화면은 이 페이지에서 찾은 단어 목록(본 단어/마스터 탭, 번역 흐리기 스위치)이고, 설정으로 들어가면 학습 언어, 기본 설정, 언어 설정, 브라우징 설정(강조·주석, 번역, 발음, 영상 자막, 기타), 더 보기 순서로 나옵니다.
- **만든 방식.** 브라우저 사이드패널이 아니라 웹페이지 위에 덧씌운 화면입니다. 사이트가 어떻게 생겼든 오른쪽에서 같은 모양으로 뜹니다.

readgloss 첫 버전은 44(버튼)·46(설정 패널)·45(퀵 메뉴)를 작게 만들고, 패널 안에는 위 추천 초안 표만 넣으면 됩니다. 단어 목록 화면(36번)은 단어장을 만든 뒤에 붙입니다.

## 근거

- **설치본(가장 믿을 만함).** 설치된 Relingo 확장 폴더의 `manifest.json`, `build/background.js`(화면 문구 사전과 기본 설정값), `build/options/index.js`(설정 화면), `build/content.css`(주석 글자 스타일). 확장 폴더는 수정하지 않았고 읽기용 사본은 scratchpad의 `relingo-features`에 있습니다.
- **공식.** relingo.net 한국어 페이지(메인, pricing, 브라우저 확장 안내 등), 영어 변경 내역(changelog v1.0.1~v3.29.0), 공식 블로그 3.1 공지, Chrome 웹스토어·Firefox 애드온 설명.
- **외부.** updf.com Relingo 비교 글, Product Hunt, extscope.org. moge.ai는 제3자 요약이라 근거가 약해서 (확인 약함)으로만 썼습니다.
- **확인하지 못한 것.**
  - 영상 컨트롤 세부, 자막 색 입력 방식, 단어 카드 섹션 순서는 번들이 압축돼 있어 확인하지 못했습니다.
  - 공식·외부 자료로는 패널의 정확한 화면 구성을 확인하지 못했습니다. 위 "떠 있는 패널" 절은 설치본 코드에서 읽은 내용입니다.
  - 가격표에 없는 기능의 유료 여부는 알 수 없습니다. 그래도 목록에서 빼지는 않았습니다.

## 검증 정정 (독립 검증자, 2026-10-06) — 위 본문보다 우선

- **#4 수준(난이도) 고르기 - 'A2~C2 사이에서 고릅니다'** — 설치본의 수준 고르기는 A2~C2가 아니다. 서버에서 받은 4단계(초급/중급/고급/전문, 단어 수 추정치 포함)를 고르는 방식이고, CEFR A1~C2는 단어장 분류(scope)로만 나온다. 'A2~C2'를 뒷받침하는 코드가 없다. readgloss의 수준 기준(B2 등)은 readgloss 쪽 설계이지 Relingo 기능 설명이 아니다.
- **#5 시험 단어장 기준 강조 - 'IELTS·TOEFL·GRE 단어 기준'** — 설치본에 IELTS/TOEFL/GRE 단어장이 없다. relingo.net에서는 검색용 키워드(SEO meta keywords)로만 'IELTS vocabulary, TOEFL vocabulary, SAT, CET, 考研, 新东方'가 나오고, 'GRE'는 'KaoYan: China's GRE'라는 라벨 한 곳뿐이다. 제품 기능으로 고를 수 있는 단어장 목록으로는 확인되지 않는다. 확인되는 시스템 단어장은 CEFR A1~C2, KaoYan(중국 대학원 시험), medical, Phrase 정도다.
- **#9 단어 진행 표시 - '강조된 단어에 몇 번 봤는지 같은 표시를 붙입니다' (확인 약함)** — 위치가 틀렸다. 이 설정(showWordProgress, 기본 켜짐, 'New' 뱃지)은 페이지 안 강조 단어에 붙는 표시가 아니라, 단어 목록 패널의 각 단어 줄 아래에 진행 막대(퍼센트)를 그리는 것이다. 코드로 확인되므로 '확인 약함'을 뗄 수 있고, 설명은 '단어 목록 줄의 진행 막대(익힘 정도)'로 고쳐야 한다. M 크기도 단어장·마스터 기능(34~36)에 의존한다고 적는 편이 맞다.
- **#11 단어 강조 방식 5종 - '배경 / 주석만 / 점선 밑줄 / 배경+주석 / 밑줄+주석'(그리고 '기본값 배경+주석')** — 값 5종(+none)은 맞지만 '배경'이 틀렸다. Relingo의 highlight는 단어 글자색을 강조색(anchor)으로 바꾸는 것이고, 노란 배경(rgba(255,223,148,.3))은 마우스를 올렸을 때만 나온다. 진짜 배경 칠은 품사 색의 'mark'(마커)뿐이다. 기본값 highlight-annotated는 '글자색 강조+주석'이다. 밑줄은 1.5px 점선이 맞다. 실제 선택지는 6개(highlight, annotated, underline, highlight-annotated, underline-annotated, none)다.
- **모양 설정 표 - '주석 글자 크기·색·투명도: 설정 없음 (본문과 같은 크기·같은 색, 투명도 60% 고정)'** — '설정 없음'과 색 상속, 투명도 60%는 오른쪽 주석(annotationAtRight)에서만 맞다. '위'(annotationAtTop) 주석은 ruby/rt 요소이고, 생성 CSS가 rt 글자 크기를 12px로 고정하며 뜻은 괄호 '(뜻)'로 감싼다. 즉 위 방식은 본문과 같은 크기가 아니다. 'Relingo도 크기 설정이 없다' 결론 자체는 유지되지만, 위 방식의 크기는 '12px 고정(발음 글자 크기 9~15px 설정과 같은 rt 공유 가능성, 미확인)'으로 고쳐 써야 한다.
- **#31 빠른 번역 창 - '웹페이지 밖에서 단어·문장을 입력해 바로 번역'** — 웹페이지 밖이 아니다. 현재 페이지 위에 덧씌우는 패널(translation-panel)이다. 떠 있는 버튼의 호버 퀵 메뉴나 단축 명령(openQuickTranslate, 기본 키 없음)으로 열린다. 'S~M 크기' 판단에는 영향이 작지만, 설명은 '페이지 위 입력 번역 패널'로 고쳐야 한다.
- **#41 플래시카드 복습 / #56 EPUB 전자책 (그리고 #42 주기 알림·복습 메일)** — 세 항목 모두 '확장 프로그램 기능'으로 읽히지만 근거가 다르다. EPUB은 설치본에 없다(MIME 표의 'epub' 문자열뿐). relingo.net 앱 소개 페이지에서 EPUB은 지원 콘텐츠 유형 목록에 있으나 바로 뒤에 'Coming soon' 문구가 있어 모바일/웹 앱 쪽 예정 기능이다('확인 약함'보다 '확장에는 없음, 앱 예정'이 정확). 플래시카드도 확장 코드에 없고 앱의 'Anki 알고리즘으로 복습'(start.p22)과 홈페이지 'Flashcards' 소개에서만 나온다. #42는 설치본에 '학습 요약 이메일(dataEmail) 일/주/월 주기 전송' 토글이 있을 뿐이고 단어 복습 알림 기능은 확인되지 않는다. 가격표 문구는 'Flush memory with daily email'이다.
- **#26 문단 번역 - 'Relingo는 문단에 마우스를 올리고 키를 누르면 번역'** — 기본값은 키가 아니라 문단 옆에 뜨는 호버 아이콘(버튼)이다. 키는 Ctrl/Shift/Alt/끄기 중 고르는 선택 사항이고 기본은 '끄기'다. 설명을 '호버 아이콘 클릭(선택 시 키 조합, 같은 키를 다시 누르면 닫힘)'으로 바꾸면 readgloss의 클릭→왼쪽 버튼 방식과 거의 같은 기능이라 상태를 🟡 대신 ✅로 봐도 된다.
- **모양 설정 표/추천 초안 - 번역 투명도 해석** — Relingo의 '전체 번역 투명도 30'은 불투명도 30%가 아니라 '30만큼 투명'(불투명도 0.7)이다. 초안 표의 'readgloss 번역 글자 투명도 30~100%, 기본 80%'를 만들 때 방향(투명도 vs 불투명도)을 헷갈리지 않게 '불투명도'로 쓰는 게 안전하다. 표의 Relingo 값(0~100, 기본 30)과 글자 크기(50~200, 기본 90)는 코드와 맞다.

- **단어 카드의 예문 라이브러리와 영상 예문 탭** — 카드에 'Sentences'(예문 라이브러리) 탭이 있고 영어 학습일 때는 '영상 예문(video)' 탭도 있다. 예문은 현재 학습 언어로 걸러지고, 단어 즐겨찾기 때 어느 단어장에 넣을지 고르는 기능(3.12.0)도 있다. 목록에는 #24(예문 번역)와 #37(저장한 문장)만 있고 '예문 라이브러리 자체'가 빠져 있다. 영상 쪽은 범위 밖이지만 텍스트 예문 라이브러리는 readgloss 사전 카드에 붙일 후보다.
