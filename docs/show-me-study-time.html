  • "지금 소제목" = 메모장이 쓰는 지금 칸 규칙과 같다(화면 위쪽에 걸친 h1~h3). 메모장이 닫혀 있어도 잰다.
  • 영상·긴 글을 가만히 볼 때 끊기지 않게 5분 여유. 동영상이 재생 중이면 멈추지 않는다.
  • 재는 것은 맥 안 다리 db에만. 페이지 글은 남기지 않는다(주소·소제목 글·초).

3. 분석에 쓰기

  • 학습노트 앞머리에 minutes, 소제목 줄 끝에 "· 12분".
  • 세션 끝에 에이전트가 learning-records에 "오래 머문 소제목 3개"를 적는다 → 튜터·다음 복습이 거기서 시작.
  • 나중에: "오래 머물렀는데 메모가 없는 소제목" = 막힌 곳 후보(내게 맞춘 주석·문장 구조와 연결).

4. 정해 둔 것(바꿀 수 있음)

  • 자리 비움 기준 5분 — 읽기만 할 때도 안 끊기게. 틀리면: 시간이 조금 부풀려짐.
  • 30초마다, 그리고 탭을 떠날 때 다리에 보냄 — 브라우저가 갑자기 꺼져도 30초 넘게 잃지 않음.
  • 하루 = 서울 날짜 기준.
