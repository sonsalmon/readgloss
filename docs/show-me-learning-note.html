1. 생각의 틀

  • 공부하며 남기는 것은 모두 메모다. 메모는 페이지의 소제목 아래에 쌓인다.
  • 메모에는 모양이 있다: 내 글 · 인용 · 개념 · 나중에 볼 것 · 단어.
  • 개념은 "이름 + 내 정의"라는 정해진 모양의 메모다. 그래서 메모장에도 보이고, 개념 탭에도 보인다. 같은 것 하나라서 어디서 고쳐도 둘 다 바뀐다.
  • 학습을 마치면 이 메모들이 모여 학습노트 한 장(마크다운)이 된다. 개념은 따로 llm-wiki 형식의 개념 페이지로도 나온다.

6. 메모장에서 개념 쓰기

  • 쓰는 칸 맨 앞에 !개념 이름을 치고 ⌘Enter → 개념 메모가 된다(다음 줄부터 정의 목록). 카드의 [내 개념으로]와 같은 결과.
  • ?이름 + ⌘Enter → 나중에 볼 것.
  • 메모장에서 개념 메모를 누르면 그 자리에서 고친다(자동 저장). 개념 탭·페이지 회색 표시에도 바로 반영.
