메모장 (브라우저 안)

readgloss 다음 조각 · 2026-10-13 · 상태: 정범 확인 대기

1. 목표

  • 정범이 웹 페이지에서 공부하면서 단축키로 메모한다.
  • 확장이 메모의 맥락을 자동으로 채운다. 정범은 맥락을 쓰지 않는다.
  • 정범이 단축키로 지난 메모를 본다. 메모를 누르면 그 페이지 그 자리로 간다.

2. 화면 (예시)

PortSwigger · Access control

…Vertical privilege escalation arises when a user can gain access to functionality that they are not permitted to access…
접근 통제 랩 › Access control › Vertical privilege escalation
portswigger.net · 지금 보는 문단 자동 기록
Enter 저장 · Shift+Enter 줄바꿈 · Esc 접기

메모장은 화면 오른쪽 아래에 뜬다. 페이지를 옮겨도 다시 뜬다(접기 전까지).

3. 단축키

키하는 일
⌥ M메모장을 연다. 이미 열려 있으면 새 메모를 시작한다.
Esc메모장을 접는다. 쓰던 글은 남는다.
Enter메모를 저장한다. 빈 칸으로 새 메모가 준비된다.
⌥ ⇧ M지난 메모 목록을 연다. 이 페이지 메모가 맨 위다.

키는 chrome://extensions/shortcuts 에서 바꿀 수 있다.

AI는 쓰지 않는다. 모두 페이지에서 바로 읽는다.

6. 만드는 순서

메모는 새 저장소(readgloss.db)에 들어간다. 그래서 "내 개념" 작업 1·2(db) 다음에 만든다.

flowchart LR
  A["T26 db"] --> B["T27 개념 저장"] --> C["T28 개념 화면"]
  A --> M["T29 메모장"]

T29는 T26이 끝나면 T27·T28과 따로 진행할 수 있다.

7. 이번에 하지 않는 것

  • 맥 전체(다른 앱, 전체 화면)에서 뜨는 메모장. → 브라우저 안 메모장을 써 본 뒤 정한다.
  • 스크린샷 끌어 넣기.
  • 메모를 AI로 정리하기. → 세션 끝에 에이전트가 한다.
