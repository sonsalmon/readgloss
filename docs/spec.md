### 10-1. 화면 흐름

1. **드래그 카드 [스크랩].** 두 단어 이상 드래그 카드의 버튼 줄에서 [단어장] 다음에 [스크랩]. 카드가 열려 있을 때만 ⌥S(Option+S)도 같은 동작. 누르면: 저장 → 그 문장에 형광펜 → 저장 확인 메시지 "스크랩했어요" + [메모](변경 기록 9의 `readglossToast` 그대로) → 선택 해제·카드 닫기([단어장] 저장과 같음). 같은 페이지의 같은 문장이 이미 스크랩돼 있으면 버튼이 [스크랩됨]이고 누르면 뺀다(형광펜도 걷는다). AI는 쓰지 않는다.
2. **할 일 줄.** 카드 맨 아래 한 줄: `→ <할 일 card_title> › <페이지 제목> › <가장 가까운 소제목>`. 할 일 이름을 누르면 목록(오늘 쓴 할 일들 · 다음 한 걸음 할 일 · 이 주소에 맞는 할 일들 · 인박스)이 뜨고, 고르면 이번 스크랩에 쓰인다.
3. **할 일 짐작**(10-3 규칙). 커리큘럼 밖 페이지면 [스크랩]을 누를 때 카드 안에 "지금 하는 '<할 일>'에 넣을까요? [넣기] [인박스]". 답은 그 페이지(정규화 주소)에 그날(서울 날짜) 동안 기억해서 다시 묻지 않는다. 후보 할 일이 없으면 묻지 않고 인박스.
4. **형광펜.** 옅은 노랑. 페이지 글은 바꾸지 않는다(10-6). 페이지를 열 때 그 주소의 스크랩을 다리에서 받아 다시 칠한다. 늦게 그려지는 페이지는 글이 바뀔 때마다 10초까지 다시 찾는다. 못 찾은 스크랩은 스크랩북에 "페이지에서 못 찾음"으로 보인다.
5. **스크랩북 탭**(패널, 순서 22 — 내 단어 20과 공부 기록 25 사이). 할 일(카드 제목 · 개수) → 페이지(제목. 같은 할 일 안의 다른 페이지 주소 아래 경로면 들여쓴다) → 소제목 → 문장(형광 표시) · 번역 · 메모. 맨 아래 인박스. 스크랩마다 [할 일 바꾸기] [메모] [지우기].
6. **그 문장으로 이동.** 스크랩북에서 문장을 누르면 같은 페이지면 그 자리로 스크롤, 다른 페이지면 지금 탭에서 그 주소를 열고 찾은 뒤 스크롤. 잠깐 진하게 깜빡여 어디인지 보여 준다.
7. **넘김 막대.** 6번으로 이동하면 화면 아래 가운데에 `스크랩 n / N  ←  →  ✕`. 같은 할 일의 스크랩을 저장 순서로 넘긴다(다른 페이지면 그 페이지를 연다). 막대가 떠 있고 입력창 밖이면 키보드 ← → 도 된다. ✕로 닫는다. 떠 있는 버튼 퀵 메뉴의 [스크랩 보기]는 이 페이지에 스크랩이 있을 때 첫 스크랩부터 막대를 연다.
8. **메모.** 저장 확인 메시지의 [메모]나 스크랩북 [메모] → 그 스크랩의 `memo`(0~1000자, 변경 기록 9와 같은 규칙).
9. **공부 기록.** 스크랩 1건 = `study-log.jsonl`에 `kind:'scrap'` 한 줄. 공부 기록 탭 종류에 "스크랩".

### 10-2. 데이터 — `data/scraps.json`(새 파일)

```json
{ "v": 1, "scraps": { "<id>": {
  "id": "정규화 주소 + exact + prefix 의 sha1 앞 12자",
  "task": "S1-04",
  "url": "https://portswigger.net/web-security/access-control",
  "title": "페이지 제목",
  "headings": ["가장 가까운 h1", "h2", "h3"],
  "quote": { "exact": "스크랩한 문장", "prefix": "앞 32자", "suffix": "뒤 32자" },
  "pos": 1234,
  "translation": "카드에 나온 번역(문맥 번역이 있으면 그것)",
  "memo": "",
  "ts": 1791443403464
}}}
```

- `task`는 `^S\d-\d{2}$` 또는 `null`(= 인박스). `exact` 1~1000자, `prefix`·`suffix` 각 ≤64자, `headings` ≤3개 × ≤200자, `title` ≤300자, `translation` ≤2000자, `memo` ≤1000자. 넘으면 400.
- 주소 정규화: `#` 뒤를 버리고, `utm_*` 쿼리만 지우고, 끝 `/`를 뗀다. 나머지 쿼리는 남긴다.
- 다리 `/scraps`(토큰 필요, 다른 주소와 같은 방식):
  - `GET /scraps` → `{scraps:[...], tasks:{id: card_title}}`(스크랩북용, `tasks`는 스크랩에 나온 할 일만). `GET /scraps?url=<주소>` → 그 페이지 스크랩만.
  - `POST /scraps` op `save`(새로 또는 같은 id면 덮되 `memo`·`ts` 유지) · `remove {id}` · `memo {id, memo}` · `move {id, task|null}` · `guess {url}` → `{task, ask, candidates:[{id, title}], matches:[...]}`(10-3).
  - 저장은 `words.json`과 같은 방식(쓰기 큐 + 임시 파일 뒤 이름 바꾸기).

### 10-4. 학습 폴더로 옮기기 — 밀린 날 따라잡기

- `npm run -s export:pending` — `data/export-state.json`의 `lastDay`(처음 값 `2026-10-06`) 다음 날부터 오늘까지, 저장 기록이 있는 날마다 `### YYYY-MM-DD` + 기존 `export:day`와 같은 "## 영어 표현 (readgloss)" 마크다운, 그 날 스크랩 개수와 할 일별 문서 이름 한 줄을 출력한다. 다리 없이 `data/`를 읽기만 한다.
- `npm run -s export:scraps -- --to <폴더>` — `scraps.json` 전체로 `<폴더>/<할일id>.md`(할 일 문서: 페이지 목록, 하위 페이지 들여쓰기, 페이지 문서 링크)와 `<폴더>/<할일id>/<페이지 이름>.md`(소제목을 `##`·`###`로, 그 아래 `>` 인용 문장 · 번역 · 메모 · 원문 주소)를 다시 만든다. 인박스는 `<폴더>/inbox.md`. 파일 머리에 "자동 생성 — 고치려면 확장 스크랩북에서". 내용이 같으면 파일을 다시 쓰지 않는다(커밋 잡음 방지). 스크랩이 사라진 할 일의 문서는 지운다.
- `npm run -s export:mark -- YYYY-MM-DD` — 에이전트가 학습 폴더에 붙이고 커밋한 뒤 `lastDay`를 그 날로.
- `npm run -s scraps -- move <id> <할일id|inbox>` — 다리 `/scraps` `move`를 토큰으로 부르는 작은 명령(인박스 분류를 정범이 승인한 뒤 에이전트가 쓴다).
- **학습 세션 절차(에이전트):** 세션을 열 때와 끝낼 때 `export:pending`을 보고, 밀린 날마다 그날 `learning-records/YYYY-MM-DD.md`에 "영어 표현" 절과 "스크랩 N개 → `scraps/<할일>.md`" 한 줄을 붙이고(파일이 없으면 만든다), `export:scraps -- --to ~/dev/learning/security-career/scraps`로 문서를 다시 만들고, 커밋한 뒤 `export:mark`. 마무리 때 인박스가 있으면 할 일 배정안을 내고 정범이 받으면 `scraps move`. 이 절차를 학습 폴더 `HANDOFF.md` 3절에 적고 메모리 `readgloss-to-learning-records`를 고친다.
- 스크랩 문서(`scraps/`)는 작업실로 올리지 않는다(작업실 설계서 7-2 정본 표에 없음). 저작물 문장이라 학습 저장소는 원격 없이 둔다.

### 10-6. 에이전트가 정한 것 (결정 — 이유 — 틀리면 드는 비용)

- 직접 만들고 부품은 `approx-string-match`(MIT, 의존성 없음)만 파일로 복사한다(라이선스 고지 포함). 다시 찾기는 Hypothesis 방식(정확 일치 → 근사 일치 → 앞뒤 문맥·위치 점수로 후보 고르기) — 조사(`docs/research/2026-10-08-scrap-tools-survey.md`) 결과 로컬 전용·소제목 아래·← → 를 다 하는 기존 도구가 없다 — 틀리면 부품 교체 한 번.
- 형광펜은 CSS Custom Highlight API(`CSS.highlights`, `::highlight()`) — 페이지 글을 바꾸지 않아 다른 기능(주석·문단 번역)과 안 부딪힌다. Aside는 Chromium 153(105부터 지원)이다 — **확장 격리 환경에서 되는지는 확인 안 했다.** T24 첫 단계에서 시험하고, 안 되면 `<mark data-readgloss>`로 감싸는 방식으로 바꾼다(그때는 주석·문단 번역과 겹치는지 시험 추가).
- 이동은 주소를 연 뒤 확장이 문장을 찾아 스크롤한다. 글 조각 주소(`#:~:text=`)는 쓰지 않는다 — 클릭하면 형광펜이 사라지고, 찾았는지 확장이 알 수 없고, 늦게 그려지는 페이지에서 불확실하다(`docs/research/2026-10-08-text-fragments.md`) — 틀리면 저장 때 조각 주소를 보조로 더한다.
- 스크랩은 `words.json` 구·문장(`phrases`)이 아니라 새 파일 — `phrases` 번호는 문장 글자로만 매겨서 다른 페이지의 같은 문장이 겹친다 — 틀리면 합치는 이전 한 번.
- ⌥S는 카드가 열려 있을 때만(전역 단축키 `commands` 안 씀) — 입력창에서 ⌥S가 ß를 치는 것과 안 부딪히고 manifest 권한이 안 는다 — 카드 없이도 원하면 그때 `commands` 추가.
- 소제목은 h1~h3, 앞뒤 문맥은 32자(Hypothesis 기본) — 기존 `headingsAbove`(`extension/selection.js`)를 다시 쓴다 — 짧으면 숫자 하나.
- 할 일 짐작은 다리가 한다(확장은 결과만 받음) — `roadmap.json`·`NOTES.md`가 맥 파일이라 — 학습 폴더 위치가 바뀌면 설정값 하나.
- 관계는 이번에 스크랩의 `task`·`url`·`headings` 칸뿐이다. 단어↔개념↔할 일의 일반 관계(점과 선)는 다음 조각 "내 개념"에서 설계한다 — 지금 만들면 쓰지 않는 구조가 생긴다 — 그때 `scraps.json`을 점으로 옮기는 이전이 한 번 든다.

3. 어려운 단어 위 자동 주석(2절 2번)은 그대로 둔다. 다만 주석 뜻을 사전 첫 뜻으로 할지 AI 문맥 뜻으로 할지는 T3 착수 때 다시 정한다(사전이 즉시·무료라 생긴 새 선택지).

# 영어 기술 문서 읽기 도우미 (브라우저 확장) 명세 초안

용어 3개만 먼저 풀어 둡니다.
- **다리(bridge)**: 확장은 브라우저 안에 갇혀 있어서 `claude` 명령을 직접 못 돌립니다. 내 맥에서 확장 대신 `claude`를 실행하고 결과를 돌려주는 작은 프로그램입니다.
- **캐시**: 한 번 받은 답을 저장해 두는 곳입니다. 같은 단어를 다시 물으면 AI를 부르지 않고 저장본을 씁니다.
- **ruby**: 글자 위에 작은 글씨를 얹는 HTML 태그입니다(일본어 후리가나 방식). Relingo식 "단어 위 작은 한국어 뜻"이 이것입니다. 조사 결과 Relingo가 정확히 이 모양인지는 문서로 확인하지 못했습니다. 이 명세는 사용자가 말한 모양을 기준으로 합니다.

## 1. 한 줄 목표

영어 보안 문서를 웹에서 읽다가, 모르는 단어는 더블클릭으로 한국어 뜻을 보고, 어려운 단어는 위에 작은 한국어 뜻이 자동으로 붙고, 문단은 한 번에 번역해서 보는 개인용 확장을 만듭니다. 번역은 API 키 없이 내 `claude` 구독으로 합니다.

## 2. 핵심 기능 3개

시간 기준은 직접 잰 값에서 가져왔습니다(2026-10-06, claude 2.1.283, haiku).
- 상주 `claude` 단어 1개: 2.9~4.0초(같은 프로세스 두 번째 호출부터)
- 상주 `claude` 문단(101단어): 2.9~5.4초
- 상주 `claude` 20단어 일괄: 1.9~4.8초
- `claude` 콜드 스타트(프로세스를 새로 띄워 단어 1개): 약 8초
- **주의: 생각(thinking) 기능을 끄지 않으면 새 프로세스의 첫 일괄 요청이 56~80초 걸렸습니다.** AI가 생각 토큰을 약 7,100개 쓰기 때문입니다. `--settings '{"alwaysThinkingEnabled":false}'`를 붙이면 같은 첫 요청이 3.7초(출력 217토큰)로 줄었습니다. `--effort low`만으로는 70.8초 그대로였습니다. 그래서 다리는 생각 끄기 설정을 반드시 붙입니다(7절 3번).

| # | 사용자가 보는 동작 | 성공 판정 |
|---|---|---|
| 1 | 영어 단어를 더블클릭하면 그 옆에 작은 말풍선으로 한국어 뜻이 뜹니다. | 캐시에 있는 단어는 0.3초 안에 뜹니다. 없는 단어는 0.3초 안에 "가져오는 중…"이 뜨고, 뜻은 6초 안에 나옵니다. 한 번 본 단어를 다시 누르면 AI 호출이 0번입니다. |
| 2 | 켠 페이지에서 어려운 단어 위에 작은 한국어 뜻이 자동으로 붙습니다. | 화면에 보이는 문단 기준으로 첫 주석이 10초 안에 나옵니다(첫 호출은 기동 포함). 같은 페이지를 다시 열면 1초 안에 나오고 AI 호출은 0번입니다. 코드 블록(`pre`, `code`)과 입력창은 건드리지 않습니다. |
| 3 | 문단 위에 마우스를 올리고 단축키(기본 Alt+T)를 누르면 문단 아래에 한국어 번역이 붙습니다. 한 번 더 누르면 사라집니다. | 100단어 문단이 6초 안에 나오고, 두 번째부터는 0.5초 안입니다. 원문은 그대로 남습니다. |

## 3. 안 할 것 / 나중에 할 것

**안 할 것**
- 영상·자막 번역.
- 단어장 동기화 서버. 나중에 단어장이 필요해지면 다리 쪽 파일 하나로 둡니다.
- 크롬 웹 스토어 게시, 남에게 배포. 약관상 개인용일 때만 안전하다는 해석이 자연스럽습니다(10절).
- 페이지 전체를 한꺼번에 이중언어로 바꾸는 기능. 문단 단위만 합니다.
- API 키(과금) 연동. CLI 로그인 토큰을 꺼내 쓰는 방식도 안 합니다. 공식 `claude` 프로그램만 실행합니다.
- codex·agy 연동은 첫 버전에서 안 합니다.

**나중에 할 것**
- PDF·EPUB: 확장 안에 자체 뷰어 페이지를 붙여서, 그 페이지에도 같은 3기능을 올립니다. relyless가 확장 안에 PDF.js 뷰어를 넣은 방식(`extension/pdf-viewer.*`, MPL-2.0)을 참고합니다.
- "알아요" 버튼: 쉬운 단어가 반복해서 주석에 붙으면 도입합니다.
- 오프라인 사전(kaikki에서 추린 영한 JSON): 캐시에 없는 단어를 기다리는 게 거슬리면 도입합니다.
- 다리에 OpenAI 호환 주소(`/v1/chat/completions`)를 하나 더 열어 기성 확장(Kiss Translator 등)도 붙일 수 있게 하는 것.
- codex 둘째 엔진. 같은 다리 안에서 엔진만 바꿉니다.

## 4. 모양 비교

- **A**: 기성 오픈소스 확장(Kiss Translator 또는 Read Frog)에 다리를 붙여, 다리가 OpenAI 호환 주소처럼 보이게 합니다.
- **B**: 직접 만드는 확장과 같은 다리.
- **F**: relyless([rockythink/relyless](https://github.com/rockythink/relyless), MPL-2.0, v0.7.1, 2026-10-05 커밋, 별 3개)를 포크해 한국어로 바꾸고, 다리를 "자체 API" 주소로 붙입니다. roamcat([dapao-777/roamcat](https://github.com/dapao-777/roamcat), MPL-2.0, 별 1개)도 같은 계열 파일 구성이라 따로 보지 않았습니다.

- **F는 기능은 가장 많지만 한국어가 막혀 있습니다.** `extension/gloss.mjs`의 프롬프트("Prefer the shortest natural Chinese word")와 응답 스키마(`pattern: HAN`), `validChinese()` 검사, `content.js`의 화면 글자('中文翻译' 등)를 모두 바꿔야 합니다.

- **혼합안의 추가 비용.** 기성 확장은 자기 캐시와 프롬프트를 쓰므로, 같은 단어를 Kiss와 자체 확장이 따로 AI에 물을 수 있습니다. 내 구독 한도가 이중으로 줄어듭니다. 캐시 공유가 되는지는 확인 못 했습니다.
- **참고용 코드.**
  - `rttr-extension`(MIT)은 실제 `<ruby>` 삽입 코드와 CEFR B2+ 선별 프롬프트가 있습니다. 별 0개에 커밋 1개라 참고용으로만 씁니다.
  - `AdaptiveTranslation`(MIT)은 수준 선택, 주석, 단어장 흐름이 Relingo와 가장 비슷합니다. 빌드 없는 바닐라 JS입니다.
  - Kiss Translator와 Read Frog는 GPL이라 읽기만 하고 복사하지 않습니다.
  - relyless(MPL-2.0)는 주석 일괄 요청 설계(`gloss.mjs`), 동적 페이지·코드 블록 건너뛰기(`content.js`), PDF 뷰어를 참고합니다. 파일을 통째로 가져오면 그 파일에 MPL 표기를 유지합니다(개인용·비배포라 의무는 가볍습니다).

## 5. 추천: B

**B를 추천합니다.** 지연 숫자와 한국어가 이유입니다.

- **단어 하나 왕복이 느립니다.** 상주 `claude`로도 3~4초, 콜드는 8초입니다. 처음 잡은 1.5초 기준을 못 맞춥니다. 그래서 "더블클릭 즉시 뜻"은 AI가 아니라 **캐시**가 해야 합니다.
- **한 단어씩 요청하면 주석이 불가능합니다.** 20개를 하나씩 물으면 약 70초(3.5초 × 20)인데, 일괄로 한 번에 물으면 2~5초입니다(생각 기능을 끈 상태). 주석은 처음부터 "화면에 보이는 단어를 모아 한 번에 묻고 캐시에 저장"하는 설계여야 합니다. A의 확장들에는 이 설계가 없습니다.
- **F(relyless)는 이 설계가 있지만 한국어로 바꾸는 비용이 큽니다.** 핵심 경로의 프롬프트·스키마·검사가 중국어 전제이고, 화면도 중국어입니다. 원본이 2주 만에 v0.7.1까지 올라온 빠른 프로젝트라 포크를 따라가기도 어렵습니다. 유지보수에 약하다는 점을 생각하면, 필요한 3기능만 가진 작은 코드가 오래 갑니다. 대신 relyless는 참고 코드로 씁니다.
- **캐시와 일괄 처리는 다리 한 곳에 있어야 합니다.** 더블클릭이 쓰는 캐시를 주석 페이지 로드가 미리 채워 주면, 더블클릭 대부분이 즉시 응답이 됩니다. B에서는 이 둘이 한 몸이지만 혼합에서는 갈라집니다.
- **B로 가도 A의 길이 막히지 않습니다.** 다리는 공통 부품입니다. B가 막히거나 지치면 다리에 OpenAI 호환 주소만 더해서 Kiss Translator로 1·3번을 곧바로 쓸 수 있습니다.

- 다리는 처음 요청이 올 때 `claude`를 띄우고, 10분 놀면 끕니다.

## 7. 에이전트가 정한 것

`결정 — 이유 — 틀리면 드는 비용` 순서입니다.

1. **확장↔다리 연결은 `http://127.0.0.1:47831` 로컬 서버(+토큰 헤더)로 합니다** — 단독 시험이 쉽고 상주 프로세스를 들고 있기 좋아서입니다. 네이티브 메시징은 Aside에서 실제 연결이 미확인이라 뒤로 미룹니다 — 틀리면 연결부 한 파일을 바꾸는 정도(기능 코드는 그대로).
2. **보안은 4겹으로 합니다.** `127.0.0.1`에만 바인딩하고, Host 검사를 하고, 임의 토큰 헤더를 요구하고, 토큰은 `/pair`가 내 확장 출처(`chrome-extension://<고정 ID>`) 하나에게만 자동으로 줍니다. 압축 해제 확장은 폴더 위치에 따라 ID가 바뀌므로 manifest에 `key`를 넣어 ID를 고정합니다 — 구독 한도를 쓰는 주소를 다른 웹페이지나 다른 확장이 칠 수 있어서입니다. 헤더가 붙으면 브라우저가 사전 확인을 강제하므로 남의 페이지가 막힙니다 — 틀리면 토큰을 손으로 한 번 붙여 넣는 수고입니다.
3. **기본 모델은 `claude` haiku 상주 프로세스입니다**(`--tools ""`, `--setting-sources ""`, `--settings '{"alwaysThinkingEnabled":false}'`, stream-json). `--bare`는 구독 로그인을 쓰지 않으므로 쓰지 않습니다 — 직접 잰 값이 가장 빠릅니다. codex 약 8초, agy 약 14초, `claude` 콜드 약 8초였습니다. 생각 끄기가 빠지면 첫 일괄 요청이 56~80초로 늘어납니다(2절). codex 구독이 최근 한도에 걸렸던 점도 반영했습니다 — 틀리면 엔진 교체 비용만 듭니다.
4. **프로세스는 요청 20건마다 재시작합니다** — 상주 세션은 대화가 쌓여 느려질 수 있어서입니다 — 틀리면 가끔 8초 지연이 한 번 생깁니다.
5. **단어 뜻 경로는 캐시 → AI 순서입니다. 첫 버전에는 사전이 없습니다** — 보안 용어(mitigate, payload, sanitize, obfuscate)는 위키 기반 영한 사전에 없고 exploit은 뜻이 틀렸습니다. 어차피 AI가 주력입니다 — 틀리면 나중에 사전 JSON을 앞단에 끼웁니다.
6. **어려운 단어 판정은 CEFR-J 1.5(A1~B2) + Octanove C1/C2로 하고, 기본은 B2 이상에 주석을 붙입니다.** 표제어는 `wink-lemmatizer`로 구합니다. 목록에 없는 단어도 후보로 보냅니다. payload·mitigate·sanitize처럼 보안 문서의 흔한 어려운 단어가 CEFR-J에 없기 때문입니다. AI가 "고유명사·코드·이미 쉬움"이면 빈 값으로 돌려 거릅니다 — 라이선스가 명확하고(합쳐서 약 280KB, CEFR-J는 인용 조건, Octanove는 CC BY-SA 4.0) 단계 설정이 쉽습니다 — 틀리면 기준값 하나를 바꿉니다. 빈 값도 캐시에 저장해서 같은 단어를 다시 묻지 않습니다.
7. **캐시는 다리 쪽 파일 `~/dev/readgloss/data/cache.json`에 둡니다** — 확장은 상태가 없고 Aside와 Chrome이 같은 캐시를 씁니다 — 파일이 깨지면 지우고 다시 받으면 됩니다.
8. **캐시 키는 소문자 표제어입니다.** 문맥이 다른 뜻은 말풍선의 "이 문장으로 다시 묻기" 버튼으로 덮어씁니다 — 다의어(exploit 등) 대응이 필요해서입니다 — 틀리면 엉뚱한 뜻이 남지만 버튼으로 고칩니다.
9. **주석은 "화면에 보이는 문단 + 한 화면 앞"만 일괄 요청합니다.** 한 번에 최대 20단어, 스크롤이 멈추면 새로 보이는 문단을 이어서 처리합니다 — 측정한 호출 크기가 20단어였고 한도 낭비를 막습니다 — 틀리면 스크롤 직후 주석이 몇 초 늦게 붙습니다.
10. **주석 자동 실행은 기본 꺼짐입니다.** 툴바 버튼으로 켜거나 "자동으로 켤 사이트" 목록에 넣습니다. 더블클릭과 문단 번역은 늘 켜져 있습니다 — 구독 한도를 지키기 위해서입니다 — 틀리면 클릭 한 번이 늘어납니다.
11. **프롬프트는 "정보보안 문서 맥락의 짧은 한국어 뜻(8자 안팎)"으로 하고, JSON만 출력하게 합니다.** 굳어진 보안 용어(취약점, 완화, 인젝션)는 그대로 쓰고 코드펜스는 파서가 벗깁니다 — 측정에서 sanitization=정제, primitive=기본 요소처럼 어색한 뜻이 나왔고 코드펜스로 감싼 출력이 나왔습니다 — 틀리면 프롬프트 수정입니다.
12. **폴더는 `~/dev/readgloss/`입니다.** 구성은 `extension/`(확장), `bridge/`(다리), `scripts/`(단어 목록 빌드), `data/`(캐시, git 제외)입니다. 원격 없는 로컬 git 저장소로 두고 push하지 않습니다 — 이름과 위치는 바꾸기 쉽습니다.
13. **언어와 빌드: 빌드 도구 없는 순수 JS(ES 모듈)입니다.** 다리는 Node 20 이상, 의존 패키지는 `wink-lemmatizer` 하나, 테스트는 내장 `node --test`입니다 — 가장 작게 시작하라는 요구와 손볼 곳이 적은 구조 때문입니다 — 틀리면 나중에 번들러를 얹으면 됩니다.
14. **라이선스: 개인용이고 배포하지 않습니다.** 참고 코드는 MIT(`rttr`, `AdaptiveTranslation`)와 MPL-2.0(relyless, 가져온 파일에 표기 유지)만 출처를 적고 가져오며, GPL 코드는 복사하지 않습니다 — 약관과 라이선스 위험을 줄입니다 — 틀리면 해당 부분을 다시 씁니다.

## 8. 완료 조건

**수용 기준**(전부 통과해야 완료입니다)
- 사용자가 고른 실제 영어 보안 글 1편(예: PortSwigger나 Project Zero 글, 바꿔도 됩니다)에서 다음을 확인합니다.
  1. 모르는 단어를 더블클릭하면 2절의 시간 안에 한국어 뜻이 나옵니다.
  2. 주석을 켜면 B2 이상 단어 위에 작은 한국어 뜻이 붙고, 코드 블록은 그대로입니다.
  3. 문단에서 단축키를 누르면 아래에 번역이 붙고, 다시 누르면 사라집니다.
- 같은 페이지를 새로 열면 AI 호출이 0번입니다(다리의 요청 통계로 확인).
- 다리를 끈 상태에서 확장이 "다리가 꺼져 있어요: 실행 방법"을 보여 주고 페이지는 깨지지 않습니다.

**자동 테스트**(작은 것 하나씩, `node --test`)
- 난이도 판정: `the`는 안 붙고, `mitigated`는 `mitigate`로 바뀌어 붙습니다.
- 캐시: 같은 단어를 두 번 물으면 두 번째는 가짜 AI 호출이 0번입니다.
- 파서: 코드펜스로 감싼 JSON도 읽고, 깨진 출력은 에러로 처리합니다.
- 인증: 토큰이 없으면 401, 남의 Origin이면 403이 나옵니다.
- 단어 쪼개기 순수 함수: 문장과 뜻 사전을 넣으면 조각 목록이 나옵니다. 브라우저 없이 시험합니다.

**수동 확인 절차**
1. 다리를 실행합니다.
2. Aside에 확장을 올립니다.
3. 보안 글 1편을 열어 2~3번 과정을 눈으로 확인합니다.
4. 다리를 껐다 켜서 캐시가 남는지 봅니다.

## 9. 4줄 요약

- **문제**: 영어 보안 문서를 읽을 때 모르는 단어를 찾느라 흐름이 끊기고, Relingo는 유료이며 구독 CLI로는 못 씁니다.
- **비용**: 돈은 0원입니다. 만드는 데 약 5세션(티켓 5개)이 듭니다. 유지보수는 내 코드 1개와 다리 1개입니다. 구독 한도는 캐시, 일괄 요청, 켠 사이트에서만 자동 실행으로 줄입니다.
- **기대 결과**: 더블클릭 뜻, 단어 위 자동 주석, 문단 번역을 구독만으로 쓰고, 한 번 본 단어는 다시 AI를 부르지 않습니다.
- **검증 방법**: 8절의 실제 보안 글 1편 수용 기준과 `node --test`를 통과하고, 같은 페이지 재방문 시 AI 호출이 0번인지 확인합니다.

## 11. 티켓 초안

한 티켓은 한 세션 분량이고, 각각 앞에서 뒤까지 닿는 얇은 조각입니다.

**T1. 뼈대: 더블클릭 → 한국어 뜻**
- 범위: `~/dev/readgloss/` 생성. 다리(`/ping`, `/pair`, `/lookup`, 상주 `claude` 호출(생각 끄기 설정 포함), 캐시 파일). 확장 뼈대(manifest와 고정 `key`, service worker, 더블클릭 말풍선). `scripts/bench.mjs`(새 프로세스 첫 호출과 이어지는 호출을 따로 잽니다).
- 완료 조건: Aside에 확장이 올라갑니다. 더블클릭하면 6초 안에 뜻이 나오고, 두 번째는 0.3초 안입니다. 인증 테스트와 캐시 테스트가 통과합니다. 다리를 끈 상태의 안내 문구가 나옵니다.
- 선행: 없음. 시간 상자: 한 세션.

**T2. 문단 번역**
- 범위: 다리 `/translate`. 문단을 찾는 코드. Alt+T 토글. 문단 해시 키 캐시.
- 완료 조건: 100단어 문단이 6초 안에, 재호출은 0.5초 안에 나옵니다. 코드 블록은 문단 대상에서 제외합니다.
- 선행: T1.

**T3. 어려운 단어 판정과 일괄 주석 요청**
- 범위: `scripts/build-wordlists.mjs`(CEFR-J 1.5와 Octanove C1/C2를 JSON으로 변환). 다리 `/annotate`(표제어 정규화, 기준 B2, 캐시 확인, 20단어씩 묶어 요청, 빈 값도 캐시에 저장). `scripts/sample-gloss.mjs`.
- 완료 조건: 난이도 판정, 파서, 캐시 단위 테스트가 통과합니다. 표본 20단어의 뜻을 사용자가 검수할 수 있게 출력합니다.
- 선행: T1.

**T4. ruby 주석 화면 그리기**
- 범위: 텍스트 노드를 쪼개 `<ruby>`로 감싸는 순수 함수와 테스트. 보이는 문단 + 한 화면 앞만 요청. 스크롤 멈춤 뒤 이어서 요청. `pre`, `code`, 입력창은 건너뜁니다. 주석 글자는 선택·복사에서 제외합니다.
- 완료 조건: 실제 보안 글에서 2번 기능의 성공 판정을 통과합니다. 재방문에서 AI 호출이 0번입니다.
- 선행: T3(그리고 T1의 확장 뼈대).

**T5. 상시 실행과 켜기/끄기**
- 범위: 툴바 버튼 켜기/끄기. "자동으로 켤 사이트" 목록. 상태 표시(다리 꺼짐, 오늘 요청 수). 다리 상시 실행(launchd 등록 파일 1개). 10분 놀면 `claude` 종료, 20건마다 재시작.
- 완료 조건: 로그인 뒤 다리가 자동으로 떠 있습니다. 8절 수용 기준 전체를 통과합니다.
- 선행: T4.

**첫 걸음(사용자가 직접 할 것, 5분)**: Aside에서 `chrome://extensions`를 열어 "개발자 모드" 토글이 있고 켜지는지 한 번만 봐 주세요. 켜지면 T1을 바로 시작합니다. 안 켜지면 Chrome으로 먼저 가고, 나머지는 같습니다.
