# 정찰 지도: 랭플릭스(Langflix) — 크롬 확장(PC) + 모바일 앱

범위: 랭플릭스의 **인풋** 쪽 고리 — 영상(유튜브·넷플릭스)을 이중자막으로 보며 단어를 찾고, 표현을 저장하고, 매일 복습하는 흐름. 말하기(섀도잉 채점·AI 회화)는 영어 튜터(english-tutor, 아웃풋용) 몫이라 뺀다.
누구를 위해: 정범 혼자 쓰는 readgloss(영어 글 읽기 확장 + 맥 로컬 다리)에 영상 인풋을 더한다. 팔 제품이 아니다.
날짜: 2026-10-26

## 핵심 고리

좋아하는 영상을 **영어+한국어 자막**으로 보다가 모르는 단어·표현을 눌러 뜻을 보고 **저장**하면, 그 표현이 **원래 장면과 함께** 매일 복습(듣기·퀴즈)으로 돌아온다.

## readgloss에 이미 있는 것

## 짐작한 데이터 모양

```
콘텐츠  id, 출처(netflix | youtube), 제목, 난이도
        근거: S05·S06·S08   확신: 보통
자막 줄  콘텐츠 id, 시작, 끝, 영어, 한국어
        근거: S01·S09(줄마다 멈추고 누름)   확신: 높음
표현    글, 종류(단어 | 숙어 | 구동사 | 전치사구), 난이도, 뜻, 용법, 예문, 발음, 해설
        근거: 출처 5 "단어, 숙어, 구동사, 전치사구", S02   확신: 높음
저장 표현  사용자, 표현 또는 직접 고른 글, 나온 장면(콘텐츠 + 시각), 복습 상태(간격 반복)
        근거: 원본 음성으로 듣기 → 장면 시각을 남긴다   확신: 보통
퀴즈 기록  저장 표현, 방식(듣기 | 객관식 | 섀도잉), 맞음/틀림, 시각
        근거: S12   확신: 짐작
```

관계: 콘텐츠 1-n 자막 줄, 자막 줄 1-n 저장 표현, 사용자 1-n 저장 표현.

readgloss에 대면: 콘텐츠·자막 줄은 저장하지 않는다(영상 페이지가 늘 가지고 있다). 저장 표현은 지금 단어장·구 항목(`words.mjs`)에 **장면(주소 + 시각, 구는 시작·끝)** 만 더하면 된다. 복습 상태는 이미 있다.

## 복제하지 않는 것

- 랭플릭스가 고른 시리즈 목록과 원어민 표현·해설 — 그 회사가 만든 편집 콘텐츠다. readgloss는 정범이 고른 아무 유튜브 영상에서 같은 일을 한다.
- 넷플릭스 영상·자막 자체 — 넷플릭스 것이다(넷플릭스 자막 표시는 아래 "다음 회차" 후보).
- 모바일 앱, 구글 로그인 동기화, 구독 결제 — readgloss는 한 사람이 쓰는 맥 로컬 도구다.
- 섀도잉 채점·AI 회화 — 아웃풋이라 영어 튜터 몫이다.

## 크기

화면 15, 흐름 6, 데이터 5. readgloss에 넣을 몫은 유튜브 자막 층 + 복습 방식 둘.
어려운 곳: ① 유튜브 자막 받기(플레이어가 직접 받아 오는 자막을 엿들어야 한다 — 유튜브가 자막 주소에 확인 값을 붙여서 확장이 따로 받기 어렵다) ② 자동 생성 자막을 문장 단위 줄로 묶기 ③ 전체 화면에서도 카드·자막이 보이게. 크기: M(이 작업 환경에서는 유튜브에 접속할 수 없어서 실제 화면 확인은 정범 몫).
